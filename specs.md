# Plan for a To Do app

Specifications
1. Simple to do app. No frills and basic.
2. It should run in a browser

Technology
- Plain HTML, CSS and JavaScript (no framework, no build step)
- Tasks saved in the browser's localStorage
- Run by opening index.html in a browser

Features
- Add a task
- Mark a task done / not done
- Delete a task
- Show count of tasks remaining
- Priority (High/Medium/Low) per task, sorted high first; click a badge to change it
- Light, pastel and dark themes chosen with icon buttons, remembered between visits
- Completed tasks shown in a separate section below, with a "Clear completed" button
- Edit a task's text and due date with the pencil button
- Undo after deleting a task or clearing completed tasks
- Optional due date per task; overdue tasks are highlighted; sorted by priority, then due date
- Search box and priority filter
